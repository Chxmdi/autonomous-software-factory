# Engineering Decision Log

## ADR-000 — Use the Software Factory

- Status: accepted
- Context: The product requires durable, evidence-driven delivery governance.
- Decision: Use the repository contracts, specialist boundaries, and release gates in this template.
- Consequences: Readiness claims require independent evidence; canonical docs must stay current.

## Decision template

- ID/status/date/owner
- Requirement and context
- Alternatives considered
- Decision and rationale
- Operational/security/cost implications
- Risks and migration/reversal cost
